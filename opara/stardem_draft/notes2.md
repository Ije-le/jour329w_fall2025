# Beatbook draft II
In refining my first draft, I generated a prompt using copilot that included a brief introduction at the beginning. The prompt also updated the existing beatbook by including a directory toward the end that had all the sources cited throughout the beatbook, their relevance /important stories they had featured in, and if possible contact information. The model returned contact information that mostly proved to be made up, especially the emails, since I couldn't trace any of them in the original public_safety_stories.json or in the first beatbook draft, so I refined the prompt to exclude contact information, and saved this version as prototype_v3
